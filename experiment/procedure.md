Procedure for the experiment:

1. Select the type of operators and the datatype you want to work with from the top bar.
2. Edit the values of variables by pressing the edit button.
3. Choose an expression prototype from the menu, or edit the expression as needed.
4. Press Next to view the step-by-step evaluation of the selected expression in the central panel, along with the corresponding reasoning in the right panel.
5. Press Stop if you want to abort the experiment and start over.

#### Manual

This experiment demonstrates the step-by-step evaluation of mathematical and logical expressions.
